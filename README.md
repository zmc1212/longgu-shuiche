# 龙骨水车 LONGGU-SHUICHE — 机构复刻 No.02

《天工开物·乃粒》翻车(龙骨水车):链轮 + 刮板闭合木链循环提水。本站三维
装配 + 闭合链运动学仿真,链节逐块沿「上行直段→上轮弧→下行直段→下轮弧」
精确摆位,流量按 Q = v·A·φ 可验算,B 键查看复原总图。

## 机构与验算

```
尺寸(复原值,宋营造尺 0.3 m):
  水槽   水平投影 5.0 m · 倾角 35° → 斜长(轮心距)Lc = 6.104 m
  链轮   R = 0.36 m(10 齿)×2;上轮心 y=3.96,下轮心 y=0.46
  链     36 节;刮板 0.30×0.055×0.03;双销 Ø0.034

闭合条件(载入期断言):
  链总长 = 2·Lc + 2πR = 14.47 m
  节距 p = 14.47/36 = 0.4019 m ⇒ N·p = 链总长(误差 < 1e-9)

链速与流量:
  v = ω·R;过水断面 A = h·W = 0.0187 m²;撒漏系数 φ = 0.72
  Q = v·A·φ:ω=0.9 → 4.37 L/s;ω=1.6(脚踏) → 7.77 L/s;ω=2.2 → 10.68 L/s
  出水频率 = v/p 次/s(每板过顶倾泻一次;单板水柱 = p·A = 7.52 L)
```

**载入期自检**:mech.js 模拟 30s 常速,刮板过顶率×A×φ 与 Q 公式偏差
> 15% 即拒绝启动。运行期 FLOW 面板以 3s 滑窗实测对照。

链节摆位(KINE):弧长参数 s = i·p + sOff 沿闭合链映射——上行直段(z=0.02,
槽内载水)、上轮半弧(z=0.13)、下行直段(z=0.26,槽外侧回程)、下轮半弧;
切向由分段解析给出,刮板面恒 ⊥ 链方向。
